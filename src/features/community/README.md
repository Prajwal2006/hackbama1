# community

Shared pieces for the subs, rides and meals boards: `CommunityBoard.tsx` (server page), `components/PostCard.tsx`, `components/CreatePostForm.tsx`, `components/PaymentAck.tsx` (also used by handoffs), `actions.ts`, and pure rules in `domain.ts` (join limits, handoff permissions, schedule windows, swap-cycle search). Data lives behind `CommunityRepository` (`src/data/community-repository.ts`).
